Regras Imutáveis (ADRs — não podem ser revertidas)

  • ✕
    FFmpeg nunca com exec() — sempre execFile() ou spawn()
  • ✕
    GOP sempre Closed + IDR + sc_threshold=0 + bf=0
  • ✕
    Áudio: two-pass R128 + True Peak verificado com BS1770GAIN
  • ✕
    Checksums: SHA-256 sempre — MD5 proibido
  • ✕
    Audit trail: INSERT-only — UPDATE e DELETE proibidos
  • ✕
    Pixel format: yuv420p obrigatório (ou yuv420p10le HDR)
  • ✕
    Auth: RS256 JWT — HS256 proibido em produção
  • ✕
    Secrets: nunca em env vars em produção — Vault ou AWS SM
  • ✕
    Filenames: nunca usados em shell commands — sempre UUID interno
  • ✓
    VMAF score calculado e guardado para todos os outputs
