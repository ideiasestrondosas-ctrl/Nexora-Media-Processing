    macOSLinuxWindows
    ✓ Esperar: "Nexora setup completo!"

    Clonar e criar a estrutura do projecto
    git clone https://github.com/[utilizador]/nexora-media-processing.git cd nexora-media-processing node scripts/nexora-scaffold.js node scripts/nexora-deploy-docs.js node scripts/nexora-finalize.js
    ✓ Esperar: "Finalização concluída!"
  • 4
    Configurar variáveis de ambiente
    cp .env.example .env # Abre .env no Antigravity e edita as passwords
    ✓ Ficheiro .env criado e editado
  • 5
    Instalar dependências e iniciar serviços
    npm install docker compose up -d sleep 30 npm run db:migrate npm run dev
    ✓ http://localhost:3000/health → {"status":"ok"}
