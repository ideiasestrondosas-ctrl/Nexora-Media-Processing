ADRs imutáveis — não reversíveis

  • ADR-01Temporal.io para orquestração (não BullMQ standalone)
  • ADR-02FFmpeg execFile/spawn isolado — nunca exec() com string
  • ADR-03SHA-256 para todos os checksums — MD5 proibido
  • ADR-04yuv420p obrigatório em todos os outputs de distribuição
  • ADR-05Two-pass EBU R128 com True Peak via BS1770GAIN independente
  • ADR-06Closed GOP + IDR frames em todos os outputs broadcast
  • ADR-07Audit trail append-only — sem UPDATE/DELETE
  • ADR-08RS256 JWT com key rotation — HS256 proibido em produção
  • ADR-09BS1770GAIN para verificação independente de loudness
  • ADR-10VMAF score calculado e guardado para todos os outputs

Checklist de aceitação final

  • ✕docker compose up -d sem erros
  • ✕GET /health/ready → 200 OK
  • ✕GOP = fps×2 verificado com FFprobe pós-encode
  • ✕BS1770GAIN confirma LUFS ±0.5 LU + True Peak ≤ -1 dBTP
  • ✕VMAF score calculado e guardado em DB
  • ✕SHA-256 calculado antes e depois de cada upload
  • ✕Audit trail imutável (sem UPDATE/DELETE no DB)
  • ✕FFmpeg nunca chamado com exec() — sempre execFile()
  • ✕tsc --noEmit + eslint sem erros
  • ✕vitest coverage ≥ 80% · QC rules 100%
  • ✕Grafana dashboard com dados reais
  • ✕WCAG 2.1 AA: axe-core sem violations críticas
